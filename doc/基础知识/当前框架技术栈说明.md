## 技术栈

| 作用       | 库                                                          |
| ---------- | ----------------------------------------------------------- |
| HTTP 服务  | NestJS 12。入口是 `src/main.ts`，模块是 `src/app_module.ts` |
| 语言       | TypeScript，ESM。相对导入带 `.js` 后缀                      |
| 依赖注入   | Nest 模块的 `providers`。用例标 `@Injectable()`             |
| 校验与报文 | `class-validator`、`class-transformer`                      |
| 访问凭证   | `@nestjs/jwt`。守卫是 `JwtAuthGuard`                        |
| 口令       | `bcrypt`                                                    |
| 数据库     | Prisma 7，SQLite，适配器 `@prisma/adapter-better-sqlite3`   |
| 配置       | `@nestjs/config` 与根目录 `.env`                            |
| 测试       | Vitest。单元测试在用例旁边，端到端测试在 `test/`            |
| 检查       | oxlint。`npm run lint`                                      |

装饰器需要 `experimentalDecorators` 和 `emitDecoratorMetadata`。构建命令是 `nest build`，默认使用 SWC。

## 和前端对齐的报文

成功响应是 `{ code: 200, message: 'ok', data }`。失败时 `code` 与 HTTP 状态相同，`data` 为 `null`。前端的 axios 拦截器在 `code === 200` 时取出 `data`。

身份接口是 `POST /auth/register`、`POST /auth/login`、`GET /auth/me`。注册和登录显式返回 HTTP 200。登录的 `data` 是 `{ token, user }`，`user` 含 `id`、`username`、`roles`。

项目接口是 `GET /projects`、`GET /projects/:id`、`PUT /projects/:id`。请求头是 `Authorization: Bearer <token>`。项目报文用 `type` 区分图形，不使用 `$modelType`。
